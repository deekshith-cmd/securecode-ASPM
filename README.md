# 🔐 Secure Code Platform with ASPM

An AI-powered coding platform designed to combine AI coding assistance and application security analysis in one place.

## 🚀 Features

- AI Coding Assistant
- Online Code Editor
- ASPM Security Scanner
- Vulnerability Detection
- Project File Management
- Code Execution Support
- Deployment Support

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## ⚙️ How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Configure the required environment variables.
5. Run `npm start`.

## 🔒 Security

Never upload API keys, passwords, or `.env` files to GitHub.
